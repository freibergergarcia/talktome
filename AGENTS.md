# AGENTS.md

Guidance for AI coding agents (and humans) working in this repository.

## What this is

TalkToMe: a macOS menu bar app for push-to-talk dictation, plus an optional
Python server that runs the speech model on another Mac.

```
app/       SwiftUI menu bar app (XcodeGen project)
server/    talktome-server: FastAPI + our own Parakeet code (MLX + NumPy), OpenAI-compatible endpoint
scripts/   deploy-server.sh (install the server on another Mac over SSH),
           make-icon.sh, make-dmg.sh (installer disk image)
docs/      README images, generated by the app's --snapshot mode
```

## Commands

| Task | Command |
|---|---|
| Generate the Xcode project | `cd app && xcodegen generate` |
| Build | `xcodebuild -project app/TalkToMe.xcodeproj -scheme TalkToMe -derivedDataPath app/build build` |
| App tests | `xcodebuild -project app/TalkToMe.xcodeproj -scheme TalkToMe -derivedDataPath app/build test` |
| Install and launch locally | `app/install.sh` |
| Render all screens to PNG | `<built app>/Contents/MacOS/TalkToMe --snapshot <dir>` |
| Run an engine on a file | `<built app>/Contents/MacOS/TalkToMe --transcribe <audio file>` |
| Regenerate the app icon | `scripts/make-icon.sh` (after editing `AppIconView.swift`) |
| Build the installer disk image | `scripts/make-dmg.sh` → `dist/TalkToMe-<version>.dmg` |
| Server tests and lint | `cd server && pip install -e '.[dev]' && pytest && ruff check . && ruff format --check .` |
| Run the server | `talktome-server serve` (needs the `mlx` extra and Apple Silicon) |

`--transcribe` uses the app's saved settings; override any of them for one
run with launch arguments, e.g. `-engine apple` or `-remoteURL http://host:8766/v1`.

## Architecture (app)

| File | Role |
|---|---|
| `HotkeyMonitor.swift` | Listen-only event tap + `HotkeyStateMachine` (tap vs hold, cancel rules) |
| `AudioRecorder.swift` | Mic → 16 kHz mono int16 PCM, live levels |
| `Microphones.swift` | Core Audio device list; skips the built-in mic when the lid is closed |
| `Transcribers.swift` | `AppleTranscriber` (SpeechAnalyzer) and `RemoteTranscriber` (OpenAI-compatible) |
| `Wire.swift` | WAV and multipart encoding, dependency-free so tests compile it alone |
| `Dictation.swift` | Orchestrates hotkey → record → engine (with fallback) → paste |
| `AppSettings.swift` | All user settings: UserDefaults, API key in the Keychain |
| `RecordingPill.swift`, `HomePanel.swift`, `SettingsView.swift`, `Theme.swift` | UI |
| `WindowRouter.swift` | AppKit menu bar item, drop-down panel, Settings window, Dock icon only while Settings is open |
| `AppIconView.swift` | The app icon, drawn in SwiftUI; `scripts/make-icon.sh` renders the asset catalog |
| `DMGBackgroundView.swift` | Installer window art; icon positions are shared with `scripts/make-dmg.sh` |

The test target compiles the pure files directly instead of hosting the app,
because launching the app starts the event tap and permission prompts. Keep
testable logic in files without AppKit/AVFoundation dependencies and add them
to `TalkToMeTests.sources` in `app/project.yml`.

## Rules

- **Never log or persist transcript text.** Not in the app, not in the server,
  not in debug logs. Log lengths, timings and loudness instead. The one
  exception is `server/parity/`, which compares transcripts of public test
  sets (LibriSpeech, FLEURS) with NeMo's; never run it on anyone's dictation.
- **No third-party code in the app.** Apple frameworks only. People run this
  on work machines; a dependency-free binary is a feature.
- **One typeface (SF Pro) and the tokens in `Theme.swift`.** Do not introduce
  new colours or fonts inline.
- **Settings live in `AppSettings`**; secrets go to the Keychain, never UserDefaults.
- **The server's HTTP contract is OpenAI's `/v1/audio/transcriptions`.** Do not
  add app-only endpoints; the app must work against any compatible server.
- **The server refuses to listen beyond localhost without a token.** Keep it that way.
- **Auth and upload size are checked in `Gate` (ASGI middleware), before the
  body is read.** FastAPI parses multipart bodies before route dependencies
  run, so never move the token check into a `Depends`.
- After UI changes, run `--snapshot` and look at the PNGs; regenerate
  `docs/images` when the change is visible in the README.
- MLX models are bound to the thread that loaded them: all model calls go
  through `ParakeetEngine`'s single worker thread.
- `features.py`, `conformer.py` and `tdt.py` reproduce NVIDIA NeMo. Any change
  to them must keep `server/parity/compare.py` at 100% identical transcripts
  (with `MLX_ENABLE_TF32=0`); see `server/parity/README.md`.

## Signing

`app/Config/Base.xcconfig` builds ad-hoc signed with a generic bundle ID.
A git-ignored `app/Config/Local.xcconfig` may override signing; never commit it.
